## 四个词先分清：住宅 IP、原生 IP、双 ISP、家宽 VDS

这四个词经常被当成同义词卖，实际指向不同的东西，也对应不同的价格。

**住宅 IP（Residential IP）** 说的是 IP 的 ASN 归属是家庭宽带运营商，不是机房。这是过平台风控的入场券，也是最核心的一项。

**原生 IP（Native IP）** 说的是 IP 注册地和服务器物理位置一致。美国机房分配的是真正注册在美国的 IP，而不是拿别国 IP 套一层美国 CDN。原生只解决"IP 是哪国的"，不解决"IP 像不像住宅"。

**双 ISP（Dual ISP）** 指同一个 IP 在两个不同民用 ISP 名下都有注册记录。意义在于容错：其中一个 ISP 的段被平台批量标记时，另一个段还能撑住。**双 ISP 不是给你两个 IP**，丽萨主机所有美国住宅 IP 套餐默认只分配 1 个 IPv4，要更多 IP 得单独加购。

**家宽 VDS** 是另一档东西。机器直接托管在美国真实民房里，走当地家庭宽带线路（西雅图 Atlas Networks、加州 Astound Broadband、加州 T-Mobile/Frontier），IP 质量比机房里的"住宅属性 IP"再高一档，代价是价格贵一倍左右，带宽和流量也更贴近真实家庭宽带的水平。

所以付费逻辑是这样的：你多付的钱买的是"平台信不信这个 IP"，不是多出来的核心数。做账号运营、跨境电商、流媒体解锁，这笔钱省不掉；只是建站、跑脚本、做中转，普通 IDC VPS 三五十块就够，没必要为家宽 IP 加预算。

## 常见问题

**双 ISP 是不是给两个 IP？** 不是。双 ISP 指同一个 IP 在两个民用 ISP 名下都有注册记录，用来提高可信度和容错。所有套餐默认 1 个 IPv4。

**住宅 IP 和原生 IP 有什么区别？** 原生 IP 说的是 IP 注册地和服务器位置一致，解决"是哪国的"；住宅 IP 说的是 ASN 归属是家庭宽带运营商，解决"像不像真人"。两者可以同时具备，也可以只有其中一个。

**68 元的 9929 精简版和 68 元的 4837 基础版怎么选？** 要低延迟和线路稳定选 9929，50Mbps/1000GB 够日常账号操作；要带宽和流量选 4837，300Mbps/3000GB，代价是晚高峰稳定性略逊。

**年付划算吗？** 确定长期用就划算。9929 年付折合约 41 元/月，叠加九折约 37 元/月；4837、纽约、芝加哥年付折合约 33 元/月。但年付过了退款期不能退，先用月付验证更稳。

**能装 Windows 吗？** 可以，官方产品页写明支持安装 Windows，但需要 2G 内存起步。

**为什么 ping 不通？** 部分 IP 段被 IP 提供方禁了 ping，官方说明这不影响实际使用。判断机器是否正常，看 SSH 或业务端口能不能连，不看 ping。
